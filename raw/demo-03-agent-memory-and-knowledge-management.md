# 演示资料 3：AI Agent 长期记忆与知识管理

> **演示数据**：本文由 AI 生成，仅用于演示知识摄取流程。它不是外部可靠来源，不含学术引用，也不应作为重要事实的证据。

## 问题背景

大语言模型（Large Language Model，LLM）的上下文窗口有限，而且一次对话中的内容不会自动成为可靠、长期的用户知识。AI Agent 若要跨任务复用信息，通常需要在当前上下文之外保存可检索的数据。

## 常见设计区分

工程系统常把记忆区分为：

- **工作记忆（working memory）**：当前任务的临时上下文、计划和中间结果。
- **情节记忆（episodic memory）**：过去发生的交互或事件记录。
- **语义记忆（semantic memory）**：整理后的概念、事实和关系。
- **程序性记忆（procedural memory）**：任务步骤、偏好或操作规则。

这些名称借用了认知科学术语，但 AI Agent 产品中的具体分类并不统一，不能直接等同于人类记忆机制。

## 知识管理的作用

外部记忆解决“如何保存和检索”的问题；知识管理还要解决“如何检查来源、合并重复概念、处理冲突和持续更新”的问题。把原始资料、整理后的知识页和索引分开，有助于回溯内容从何而来。

LLM Wiki 可作为一种本地 Markdown 知识编译环境：原始资料保存在 raw/，整理后的页面位于 wiki/，模型可据此协助查询和维护。其回答仍需核对来源和适用条件。

## 安全与质量边界

记忆中可能出现过时、错误或敏感信息。系统应限制收集范围、保留来源、区分事实与推论，并让用户审核重要写入。向量检索或长上下文都不能代替这些治理步骤。
